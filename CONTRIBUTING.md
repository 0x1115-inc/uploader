# Contribution

We welcome contributions to the uploader project! Whether it's a bug fix, a new feature, or documentation improvements, your help is appreciated. Please follow the guidelines below to contribute effectively.

## Folder structure
First of all, please familiarize yourself with the project structure:

```
uploader/
├── apis/               # API definitions and handlers
├── build/              # Build artifacts (e.g., Docker images)
├── cmd/                # Main application entry points
├── internal/           # Internal packages (not for external use)
├── pkg/                # Public packages (can be imported by other projects)
├── deployments/        # Deployment configurations (e.g., Docker Compose)
├── scripts/            # Utility scripts (e.g., for Docker Compose)
```
